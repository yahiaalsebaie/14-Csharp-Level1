# C# Windows Forms Learning Application

## 📋 Project Overview

This is a comprehensive Windows Forms learning application built with C# and .NET Framework 4.7.2. The project serves as an educational resource demonstrating various Windows Forms controls, components, and their implementations. It provides hands-on examples of common UI patterns and form interactions.

This project is part of **Course 14 – C# – Level 1** by [Programming Advices](https://programmingadvices.com), where the concepts are applied through practical exercises and hands-on projects.

**Repository:** https://github.com/yahiaalsebaie/14-Csharp-Level1

## 🎯 Project Features

The main application (`frmMain`) serves as a launcher for multiple demonstration forms, each showcasing specific Windows Forms controls and concepts:

- **Multi-Form Navigation** - Demonstrates opening forms modally (`ShowDialog()`) and non-modally (`Show()`)
- **Event Handling** - Button click events triggering form launches
- **Form Management** - Multiple form instances and window control

## 🧭 Learning Path

### Phase 1: Core C# Fundamentals (Beginner Projects)
1. **Start with BarcodeSimulation**
   - Understand strings and type conversion
   - Learn collection basics with `List<T>`
   - Practice string formatting and manipulation

2. **Then explore CSharpDataTypeChecker**
   - Understand all numeric data types
   - Learn about type ranges and limitations
   - See real-world applications of type conversion

### Phase 2: Windows Forms UI Development
- Once comfortable with C# basics, explore the 24+ forms in `WindowsFormsApp1`
- Learn how to build interactive user interfaces
- Understand event-driven programming
